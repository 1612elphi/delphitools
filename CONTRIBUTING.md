# Contributing to delphitools

Thanks for your time! I'm glad you're interested in contributing to delphitools.

By default, all contributions to delphitools are welcome *within reason*. If you'd like to contribute to delphitools, please adhere to the following guidelines:

# Content we accept

- Technical corrections
- New tools, provided they solve a problem you've actually had
- Typographical and visual fixes
- Well scoped, well reasoned solutions to problems

# Content we do not accept

- Any code that requires a server component to run. delphitools is and will always be local-only
	- The only exception to this is loading large files like ML models or WASM binaries from trusted CDNs and sources.
- Any and all code purely generated by an AI agent with no human oversight. See AI-POLICY.md for details on this.

# How to contribute

To contribute, please first fork the repository and make your changes. A new tool must be registered in three places: 

1. A component at `app/components/tools/<id>.gts`.
2. A metadata entry in `app/lib/tools.ts` with ID, name, description, Lucide icon name and href. This registers the tool.
3. Styles as Crayon-compatible style files at `app/styles/tools/_<id>.scss` as well as `@use "tools/<id>"` in `app.scss`.
	- If a new icon is used, please run `bun scripts/gen-icons.mjs`.
4. Add a row to the `PARITY.md` file. The web repo is the authoritative truth on this state.

# Conventions to keep in mind

- delphitools uses British spelling, meaning "colour" and "optimise", "centre" and "grey".
- Tool IDs are kebab-case, class names are prefixed with `dt-`.
- Adhere to the established design style.
- If adding a colour tool, read the user's preferred notation from the header selector. Tools can accept a colour via a `?color=` query string as defined in `lib/colour-query.ts`.
- All code is linted using `bun run lint` using ESLint and adheres to Kernel-style Linux spacing rules (Tabs over Spaces).

# Finishing up

Before you can submit your work as a pull request, you must run QUnit tests using `bun run test` or similar. **By submitting your work you agree to it being licensed under Zero-Clause BSD.**
